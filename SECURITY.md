# Security policy

Please report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/excel16061/RouteMock/security/advisories/new).
Do not open a public issue. If that page is unavailable, the repository owner still
needs to enable the feature in the repository's security settings.

Please include what is affected, how to reproduce it, and the impact. Do not test against
systems you do not own, and do not access other people's data.

This is a personal research project with no support commitment or guaranteed response
time. It has had no independent security audit or penetration test.

See [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) for known risks and limitations.
