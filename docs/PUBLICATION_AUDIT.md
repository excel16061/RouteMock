# Publication audit

Scope: all 222 published files, including hidden files and the final reports. These are automated text searches plus inspection of every image. A clean result
is not proof that nothing sensitive remains, and this cannot cover caches, forks, or other copies.

## Excluded from publication

Git ignores all of these. Each rule was checked, and no such file is in the publishable set.

| Category | Examples |
| --- | --- |
| Tool transcripts and local AI configuration | `.claude/` |
| Raw device logs, captures, and consent receipts | `device-logs/`, `logcat*.txt`, `bugreport*`, `consent-receipt*.json` |
| Secrets and credentials | `.env`, `dashboard/.env`, keystores, service-account files, `*.pem`, `*.key` |
| Databases, dumps, and uploaded evidence | `*.sqlite3`, `*.db`, `*.dump`, `dashboard/private-evidence/` |
| Local toolchain paths | `env.sh`, `local.properties` |
| Build outputs | `build/`, `app/build/`, `*.apk`, `*.aab`, `.gradle/`, `.kotlin/` |
| Dependencies and caches | `dashboard/.venv/`, `__pycache__/`, `.DS_Store` |

`dashboard/.env.example` is the one exception to the `.env` rule, and holds placeholders only. Local
secrets stay on the local machine with owner-only permissions. The local coding setup is not affected.
