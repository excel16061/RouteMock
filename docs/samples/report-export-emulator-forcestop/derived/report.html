Deviations

Mock-app selection had not persisted across the previous emulator shutdown and was redone in Settings. The observer app was installed on the emulator for this run and removed afterwards. Its location permission was granted through its own prompt by the test automation. Its post-relaunch counts from the first session are not used, because it ends observation when it leaves the screen. The first normal-Stop attempt was refused because the draft route is not kept across a restart; the saved route was reloaded.
